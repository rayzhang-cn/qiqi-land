# 奇奇乐园 —— 儿童学习系统设计文档

日期：2026-10-11
状态：已通过分节评审，待用户终审

## 1. 背景与目标

为家中两个孩子（3 岁与 6 岁）开发的趣味学习系统，iPad 平板使用，覆盖语言与识字、数学与逻辑、科学与自然、艺术与创造四大领域，外加古诗背诵模块（孩子已会背 32 首古诗，需支持复习 + 拓展新学）。

核心矛盾：孩子消耗内容快 vs 家长业余时间少 → 采用**游戏模板引擎 + 数据驱动内容**架构，新增内容只写 JSON 不写代码。

### 已确认需求

- 设备：iPad/平板，触屏交互
- 形态：PWA 网页应用，添加到主屏幕全屏运行，全离线
- 主结构：地图自由探索（骨架） + 每岛屿内故事冒险线（玩法）
- 双孩子档案，各自独立进度与难度档（3-4 岁 / 5-6 岁）
- 家长功能：屏幕时间控制、学习进度报告、难度手动调整
- 3 岁孩子不识字 → 全部指引语音播报（TTS）
- 无后端、无账号、无网络依赖、无隐私收集

## 2. 整体架构与技术栈

```
┌─────────────────────────────────────────────┐
│              PWA (iPad 主屏幕图标)            │
│  ┌───────────────────────────────────────┐  │
│  │         React + TypeScript + Vite      │  │
│  │  ┌─────────┐  ┌─────────┐  ┌────────┐  │  │
│  │  │ 地图/岛屿│  │ 游戏模板 │  │ 家长中心│  │  │
│  │  │   UI     │  │  引擎   │  │  (PIN) │  │  │
│  │  └────┬─────┘  └────┬─────┘  └───┬────┘  │  │
│  │       └─────────────┼────────────┘       │  │
│  │             ┌───────▼────────┐           │  │
│  │             │  内容数据层     │           │  │
│  │             │ (JSON 关卡包)  │           │  │
│  │             └───────┬────────┘           │  │
│  │             ┌───────▼────────┐           │  │
│  │             │  本地存储       │           │  │
│  │             │ localStorage / │           │  │
│  │             │ IndexedDB      │           │  │
│  │             └────────────────┘           │  │
│  └───────────────────────────────────────┘  │
│   语音: Web Speech API (TTS) 离线可用         │
│   音频: 音效/配乐本地打包                      │
└─────────────────────────────────────────────┘
        无后端 · 无账号 · 全离线
```

- **Vite + React 18 + TypeScript**：组件化适合模板引擎
- **Zustand**：轻量状态管理（当前档案、进度、设置）
- **Framer Motion + CSS 动画**：界面动效；游戏交互用 DOM/触摸事件，不引游戏引擎
- **vite-plugin-pwa**：Service Worker 离线缓存
- **Web Speech API（speechSynthesis）**：中文语音播报，iPad 原生支持、离线、零成本；不可用时降级为文字+音效
- **localStorage** 存档案与设置，**IndexedDB（idb）** 存学习记录

## 3. 部署路径（Mac 开发 → iPad 使用）

1. **开发调试**：`npm run dev -- --host`，iPad 同 Wi-Fi 访问 `http://<Mac-IP>:5173` 实时预览
2. **正式部署**：推送 GitHub → Cloudflare Pages（或 GitHub Pages/Vercel）自动构建，HTTPS 是 Service Worker 生效前提
3. **iPad 安装**：Safari 打开部署网址 → 分享 → 添加到主屏幕 → 全屏独立 App，首次加载后永久离线
4. **更新**：`git push` 后孩子下次联网打开自动更新；本地进度不受影响

## 4. 游戏模板与内容模型

### 9 个游戏模板

| # | 模板 | 玩法 | 内容示例 |
|---|------|------|----------|
| 1 | 点选认知 | 听语音/看图，点正确卡片 | 认颜色、认汉字、认动物 |
| 2 | 配对连线 | 左右两列点选/拖拽配对 | 拼音配汉字、数字配数量、动物配脚印 |
| 3 | 数数运算 | 数物体、选答案 | 数苹果、10 以内加减（图示辅助） |
| 4 | 拖拽分类 | 物品拖进正确的框 | 形状分类、声母韵母分类 |
| 5 | 涂色画板 | 自由涂鸦/按提示涂色 | 艺术领域、颜色认知 |
| 6 | 顺序拼图 | 按规律/顺序排列 | 大小排序、数字规律、诗句排序 |
| 7 | 听力选择 | 纯语音出题选答案 | 英语单词听力、儿歌接龙 |
| 8 | 描红临摹 | 手指沿轨迹描画 | 汉字笔画、字母书写（5-6 岁档） |
| 9 | 诗词乐园 | 古诗综合玩法（见下） | 32 首存量诗 + 约 20 首新诗 |

### 诗词乐园子玩法

| 子玩法 | 说明 | 适合 |
|--------|------|------|
| 听诗跟读 | TTS 逐句朗诵，诗句 karaoke 式高亮 | 3-4 岁磨耳朵 |
| 诗句补全 | "床前明__光"，3 个字卡选正确的字 | 5-6 岁复习 |
| 诗句排序 | 打乱诗句拖回正确顺序 | 5-6 岁 |
| 诗配画 | 听诗句选符合意境的画面 | 两个年龄档 |

### 内容组织层级

```
领域（4 个岛屿）
 └── 故事线（每岛 1 条 + 语言岛附加「诗词小径」）
      └── 章节（3-5 个）
           └── 关卡（每章 5-10 关，引用模板 + 数据）
```

### MVP 内容量

每岛 1 条故事线 × 2 章 × 6 关 ≈ 48 关 + 诗词小径 32 首复习诗，之后每周增量添加。

### 实施分期

- **里程碑 1（可玩骨架）**：项目脚手架 + PWA 离线 + 地图/档案选择 + 模板①③ + 数学山 1 章 + 本地进度存储
- **里程碑 2（古诗上线）**：模板⑨诗词乐园 + 32 首古诗数据 + 语言岛「诗词小径」
- **里程碑 3（内容铺开）**：其余 7 个模板 + 四岛故事线 + 48 关内容
- **里程碑 4（家长中心）**：屏幕时间、进度报告、难度调整、设置
- 每个里程碑结束都是孩子可直接玩的完整状态

## 5. 故事线与岛屿设计

总地图「奇奇乐园」：4 座岛屿 + 中央家园。孩子自选吉祥物伙伴（小恐龙🦖/小兔子🐰/小机器人🤖）全程陪伴。

| 岛屿 | 领域 | 故事线 | 章节示例 |
|------|------|--------|----------|
| 🔤 语言岛 | 语言与识字 | 「拼音精灵失踪了」 | 汉字小镇、诗词小径、英语角 |
| 🔢 数学山 | 数学与逻辑 | 「修理数字过山车」 | 数数谷、加减工厂、形状迷宫 |
| 🦕 科学森林 | 科学与自然 | 「恐龙妈妈的蛋」 | 动物王国、四季天气、小小宇航员 |
| 🎨 艺术城堡 | 艺术与创造 | 「颜色大盗」 | 涂鸦画室、颜色实验室、节奏音乐厅 |

**关卡内节奏（每关 2-4 分钟）：**

```
进入关卡 → 伙伴 1 句话推进剧情（语音+气泡）
→ 玩游戏模板 → 成功 → 星星+音效+剧情前进
→ 失败 → 鼓励语音 + 引导式提示再试（永不"判死"）
```

- 章节奖励：新场景装饰或伙伴装扮，在中央家园展示，形成长期收集动力
- **无惩罚设计**：答错不扣减，只有提示（"再看看哦，苹果是红色的那个"）
- 故事文本与游戏数据同等地位，均为数据文件，可随时修改

## 6. 双孩子档案与难度系统

```
启动页：选角色进入（大头像 + 名字，无需密码）
 ├─ 档案A（3 岁档）─ 独立进度、星星、装扮、学习记录
 └─ 档案B（6 岁档）─ 独立进度、星星、装扮、学习记录
```

### 年龄档规则

| | 3-4 岁档 | 5-6 岁档 |
|---|----------|----------|
| 单次关卡时长 | 1-2 分钟 | 2-4 分钟 |
| 操作 | 点按为主，大按钮 | 拖拽、描红 |
| 文字依赖 | 几乎为零，全语音 | 语音+文字并行 |
| 题目复杂度 | 2-3 选项，具体形象 | 3-4 选项，可抽象 |
| 古诗 | 只听读欣赏 | 补全、排序、诗配画 |

### 难度自适应（每档案独立）

- 每知识点记录最近 5 次正确率
- 连续 3 次全对 → 该知识点降频（已掌握）
- 正确率 < 60% → 下次出现前插入更简单的铺垫关
- 家长可手动覆盖（按领域调档）

### 存储结构

```jsonc
// localStorage: profiles
{
  "active": "child-a",
  "profiles": {
    "child-a": { "name": "小宝", "avatar": "🦖", "ageBand": "3-4", "createdAt": "..." },
    "child-b": { "name": "大宝", "avatar": "🤖", "ageBand": "5-6", "createdAt": "..." }
  }
}
// IndexedDB: 每档案的关卡进度、知识点正确率、星星、解锁记录
```

## 7. 家长中心

入口：首页小齿轮 → 家长自定义 4 位 PIN，防孩子误入。

| 功能 | 内容 |
|------|------|
| ⏰ 屏幕时间 | 每日时长上限（默认 20 分钟）；到时"休息眼睛"动画锁定至次日；每 10 分钟喝水/远眺提醒 |
| 📊 进度报告 | 每孩子：本周时长、各岛完成度、知识点掌握热力；古诗单独列表（已复习/新学/熟练） |
| 🎚️ 难度调整 | 按领域手动调档，覆盖自适应结果 |
| ⚙️ 设置 | 语音开关/语速、音乐音量、重置单个档案 |

## 8. 错误处理

- **孩子面前永不报错**：任何异常表现为伙伴温柔台词（"哎呀，出了点小问题，我们再试一次"）+ 自动重试
- TTS 不可用 → 降级文字+音效
- 关卡数据损坏/缺失 → 跳过并记录，不阻断流程
- localStorage 写失败 → 内存中继续玩，家长中心提示
- 异常静默写入本地日志，家长中心可查看/导出

## 9. 测试策略

- Vitest 单元测试：模板判分逻辑、难度自适应算法（重点）
- **JSON Schema 校验脚本**：所有关卡/古诗数据必须过校验（数据驱动的命脉）
- Playwright 端到端：选档案 → 进岛 → 玩一关 → 得星星
- 真人验收：两个宝贝试玩
