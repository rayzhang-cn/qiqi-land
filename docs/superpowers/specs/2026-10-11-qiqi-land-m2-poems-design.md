# 奇奇乐园 · 里程碑 2「古诗乐园」设计文档

日期：2026-10-11
状态：设计已确认（用户已授权继续）

## 1. 背景与目标

M1 已交付可玩的数学山（模板①③ + 12 关 + PWA）。M2 上线**语言岛「诗词小径」**：孩子自由点选古诗、整首连播跟读（逐字高亮），听完自动得星。

内容：32 首已会古诗（familiar: true，复习）+ 20 首新学古诗（familiar: false，磨耳朵/新学）= **52 首**。

## 2. 范围

- 模板⑨ 诗词乐园，**仅「听诗跟读」一种玩法**（整首连播 + karaoke 逐字高亮）
- 语言岛解锁；诗词小径独立浏览界面（自由点选，无顺序解锁）
- 完成判定：**听完一遍自动得星**
- 护眼配色硬约束
- 附带改进：TTS 手势门控、PNG 图标、全屏 meta

**明确不在 M2 范围**：诗句补全、诗句排序、诗配画（后续里程碑）；IndexedDB 进度迁移、地图档案切换（M4 家长中心）。

## 3. 架构

```
src/content/schema.ts        — 新增 PoemSchema（独立内容类型，非 LevelData 的 template 分支）
src/content/poems/*.json     — 52 首诗数据（新目录，独立于 levels/）
src/content/index.ts         — 新增 getPoems() 加载
src/templates/PoemRecital.tsx — 整首连播 karaoke 逐字高亮组件
src/screens/PoemList.tsx     — 诗词小径诗单（自由点选）
src/App.tsx                  — 新增 screen 'poem-list' | 'poem-recital'
src/screens/WorldMap.tsx     — 语言岛 open
src/theme.css                — 诗词相关样式 + 护眼配色变量
scripts/validate-content.ts  — 扩展校验 poems/ 目录
```

**关键决策：**
1. 诗词**不强制顺序解锁**（诗之间无依赖，复习场景自由点选），用独立 PoemList 界面，不走 ChapterView
2. 逐字高亮：TTS `onboundary` 驱动，不可用时退化为「按字数均分句时长定时高亮」；每句运行时 `Array.from(line)` 拆字，JSON 只存整句（去标点）
3. 听诗跟读面向两个年龄档，不做 ageBand 区分；`familiar` 只用于诗单「已会/新学」标记

## 4. 诗数据模型

`PoemSchema`（zod）：

```ts
{
  id: string;          // "poem-jingyesi"
  title: string;       // "静夜思"
  author: string;      // "李白"
  dynasty: string;     // "唐"
  lines: string[];     // ["床前明月光", ...] 去标点、非空、至少 2 句
  familiar: boolean;   // true=已会背 false=新学
}
```

## 5. 界面与护眼配色

**诗单 PoemList：**
- 标题「诗词小径」+ 一句故事导入
- 52 首诗卡片列表（可滚动），每张显示：诗名、作者、朝代、`已会`/`新学` 小标记
- 自由点选，无锁定

**跟读 PoemRecital：**
- 顶部：诗名 · 作者 · 朝代
- 中部：全诗逐行竖排居中，当前朗读的字盖低饱和高亮块
- 底部：大「▶️ 开始听」/「⏸」播放按钮 + 「🔁 再听一遍」
- 播完最后一字 → 自动得星 → 奖励视图 → 返回诗单

**护眼配色（硬约束，写入 CSS 变量）：**

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | `#F5F1E8` | 柔和米白，低刺激 |
| 正文文字 | `#3E2723` | 深棕，对比 >12:1 |
| 次要文字 | `#8D6E63` | 中棕 |
| 高亮块 | `#C8E6C9`（浅绿）或 `#FFE0B2`（浅橙） | 低饱和，文字不变色 |
| 主按钮 | `#EF9A9A`（柔和暖橙） | 深字，非白字 |

原则：**高亮块低饱和、文字永远保持高对比，禁用亮黄底/白字**。

## 6. 完成判定与数据流

```
PoemList → 点诗 → PoemRecital（整首连播逐字高亮）
  → 播完最后一字 → 自动 recordAttempt(档案id, 诗id, true, 1星)
  → 奖励视图（⭐ + 「背得真好！」）→ 返回诗单
```

- 统一每首 1 星
- 进度复用现有 `useProgressStore`，诗 id 即关卡 id
- **TTS 手势门控**：PoemRecital 挂载时不自动播放，显示「▶️ 开始听」按钮，点击处理器内调 `speak`（iOS 才会播）
- 顺带修 M1 终审 #3：GameEngine 数学关卡加「听一听」重播按钮

## 7. 错误处理

- TTS 不支持 → 只显示文字静默降级（复用 useSpeech）
- `onboundary` 不触发 → 定时均分高亮降级
- 诗 JSON 损坏 → schema 校验过滤（复用现有机制）
- 孩子面前永不报错：异常表现为伙伴温柔台词 + 自动重试

## 8. 测试策略

- PoemSchema 单测（合法/非法、lines 非空、familiar 布尔）
- 拆字/去标点工具函数单测
- PoemRecital 组件测试（点播放调 speak、播完触发 onComplete、高亮推进 mock timer）
- PoemList 渲染 52 首、点选触发
- `validate:content` 扩展校验 poems 目录
- e2e：进语言岛 → 诗词小径 → 点一首 → 播放 → 得星

## 9. 附带改进

- 180×180 + 512×512 PNG 图标（替换 SVG apple-touch-icon）
- `index.html` 补 `apple-mobile-web-app-capable` + `viewport-fit=cover`
- `manifest` 加 `lang: 'zh-CN'`
